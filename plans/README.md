# Plans

Use this directory for task-specific plans that may span multiple sessions.

For a multi-session feature, create `plans/<feature-slug>.md` before implementation. Keep the plan self-contained and updated with:

- goal and scope
- current status
- next concrete steps
- files likely to change
- validation commands and results
- blockers or open questions

Do not create a plan for trivial single-session edits. If a plan becomes active, reference it from `docs/ai/CURRENT.md` and `docs/ai/HANDOFF.md`.
