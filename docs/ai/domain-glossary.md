# Domain Glossary

| Term                     | Meaning                                                                            | Source / where seen                                                                         | Notes                                                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Account                  | User-owned profile data attached to an authenticated identity.                     | `core/account/domain/account.ts`                                                            | Includes id, email, nullable display name, onboarding status, and lifecycle timestamps.                                                    |
| Account owner            | The implied end user who owns an account.                                          | `core/account/domain/account.ts`, Account use-cases                                         | Product-specific role name is Unknown.                                                                                                     |
| AuthUser                 | Minimal authenticated identity returned by login or registration.                  | `core/auth/domain/auth.ts`                                                                  | Contains id and email. Distinct from `Account`.                                                                                            |
| Session                  | Authentication token state for the current user.                                   | `core/auth/domain/auth.ts`                                                                  | Redux owns runtime truth; SecureStore persists the validated value across native launches. Do not store real token values in memory files. |
| AccountOnboardingStatus  | Durable Account lifecycle controlling whether the user can enter the main app.     | `core/account/domain/account.ts`                                                            | Values: `pending`, `completed`; no parallel session flag.                                                                                  |
| AuthState                | Durable authentication runtime state.                                              | `core/auth/domain/slice.ts`                                                                 | Tracks only the current user and session. Connection derives from the presence of the session.                                             |
| AuthError                | Stable authentication failure independent from infrastructure and translated copy. | `core/auth/domain/auth-error.ts`                                                            | Business codes belong to auth; technical categories are shared. Raw backend messages never cross the adapter.                              |
| RegisterPayload          | Credentials required to register an identity.                                      | `core/auth/apis/types.ts`                                                                   | Email and password only; Account owns profile data.                                                                                        |
| LoginPayload             | Email/password credentials for standard login.                                     | `core/auth/apis/types.ts`                                                                   | Used by the `/login` auth gateway request.                                                                                                 |
| UpdateAccountPayload     | Editable Account profile fields.                                                   | `core/account/apis/types.ts`                                                                | Updates `displayName`; onboarding uses its dedicated semantic operation.                                                                   |
| Subscription             | Current premium entitlement and renewal metadata.                                  | `core/subscription/domain/subscription.ts`                                                  | Singleton state for current account's subscription.                                                                                        |
| SubscriptionTier         | Product access tier granted to the account.                                        | `core/subscription/domain/subscription.ts`                                                  | Values: `free`, `premium`.                                                                                                                 |
| SubscriptionStatus       | Provider-normalized premium lifecycle state.                                       | `core/subscription/domain/subscription.ts`                                                  | Values: `inactive`, `trialing`, `active`, `canceled`.                                                                                      |
| SubscriptionPlan         | Commercial billing interval for premium access.                                    | `core/subscription/domain/subscription.ts`, `core/subscription/domain/subscription-plan.ts` | Values: `annual`, `monthly`.                                                                                                               |
| SubscriptionOffering     | Sellable premium option displayed before purchase.                                 | `core/subscription/domain/subscription-offering.ts`                                         | Includes id, plan, title, price label, period label, and optional badges/details.                                                          |
| SubscriptionActionResult | Successful subscription action that can change entitlement.                        | `core/subscription/apis/types.ts`                                                           | Contains the normalized subscription and selected plan; failures travel through `SubscriptionResult`.                                      |
| Premium                  | Paid access state.                                                                 | `core/subscription/adapters/selectors/subscription-selectors.ts`                            | Selector treats `premium` with `active` or `trialing` as premium.                                                                          |
