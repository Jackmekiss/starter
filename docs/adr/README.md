# Architecture Decision Records

No formal ADR files existed when the project memory system was initialized.

Use [../ai/DECISIONS.md](../ai/DECISIONS.md) for compact durable decisions. Create a dedicated ADR in this folder when a decision needs more context than the compact table can hold.

Recommended ADR filename:

```txt
YYYY-MM-DD-short-decision-title.md
```

Recommended ADR structure:

```md
# <Decision Title>

Date: YYYY-MM-DD

## Status

Proposed | Accepted | Superseded

## Context

## Decision

## Consequences

## Alternatives Considered
```
